This folder contains the v2 of the blobber module.
It only contains library code and no CLI code.
The NOTES.md file in the root of this directory contains notes on what's changing for v2.

As part of this rewrite, we are heavily focusing on the quality of the code.
This means we will be writing less code, but it will be of higher quality.
We will be using the best practices of software development.
We will put special emphasis on proper abstractions and modularity.
Especially the contracts between different components.

IMPORTANT: Code written in this directory will be heavily under the control of a human operator.
Do not write large swaths of code at once.
Never write more than the human operator asks.
Do not assume that we are doing things the exact same way as v1.
Always ask the human operator for confirmation before making significant changes.
The human operator will approve and sign off on each change before it is committed.
